# Product Insights Hub — Prototype Documentation

**Product:** Insights Hub — Trade Me
**Type:** Internal product management tool
**Purpose:** Aggregate, analyse, and act on customer feedback to help product teams prioritise their roadmap.

---

## Overview

Insights Hub is a single-page web application that ingests feedback from multiple data sources (Salesforce, CSAT surveys, NPS responses, Slack) and surfaces patterns, trends, and AI-generated opportunities to product teams. It bridges raw customer feedback and roadmap decisions.

**Navigation** consists of 7 pages accessible from the left sidebar:

| # | Page | Purpose |
|---|------|---------|
| 1 | Dashboard | At-a-glance health of all feedback |
| 2 | Opportunities | AI-generated, prioritised improvement items |
| 3 | Feedback Explorer | Browse and filter raw feedback records |
| 4 | AI Assistant | Chat with Claude about your feedback data |
| 5 | Opportunity Sizing | Quantify impact before committing to work |
| 6 | Sources & Settings | Manage data connections and saved views |
| 7 | Add Feedback | Manually capture ad-hoc feedback |

## Page 1 — Dashboard

![Dashboard](screenshots/01-dashboard.png)

### Description
The home view. Summarises the last 30 days of feedback across all connected sources at a glance.

### Key Components

**Summary metrics (top row)**
| Metric | Value | Signal |
|--------|-------|--------|
| Total feedback | 2,847 | ↑ 14% vs last month |
| Open opportunities | 40 | ↑ 6 new from B2B data |
| Trending themes | 8 | ↑ 3 since yesterday |
| Avg sentiment | 62% | ↓ 4% vs last month |

**AI Summary box**
An auto-generated digest of the week's most important issues, written in plain English. Highlights emerging spikes, persistent themes, and any legal/compliance signals from B2B data.

> _"Top issues this week: checkout payment failures (up 40%), search relevance on mobile (persistent, 3 weeks), and seller fee confusion after recent pricing changes."_

**Top Trending Themes panel**
Ranked list of themes with a spark bar showing relative volume and a mention count. Themes flagged as `Urgent` or `↑ spike` are highlighted. Clicking a theme navigates to the Feedback Explorer pre-filtered to that theme.

**Feedback Volume — Last 7 Days**
A bar chart showing daily feedback volume for the past week, allowing quick visual detection of spikes.

**Alerts panel**
Real-time threshold alerts (e.g. "Payment failure mentions up 40% in 24h"). Each alert is timestamped and clickable to explore the underlying feedback.

**Feedback by Source**
Donut chart + legend showing the breakdown of feedback volume by source:
- Salesforce cases — 1,204 (42%)
- CSAT surveys — 847 (30%)
- NPS responses — 512 (18%)
- Slack feedback — 284 (10%)

## Page 2 — Opportunities

![Opportunities list](screenshots/02-opportunities.png)

### Description
A prioritised list of product improvement opportunities. Opportunities are **auto-generated by AI** from clusters of related feedback, or can be created manually via `+ New`.

### Key Components

**Filter toolbar**
Tabs to filter by status: `All` · `Urgent` · `Under review` · `On roadmap` · `Backlog` · `Done`

**Opportunity cards**
Each card shows:
- Title (AI-generated or manually named)
- Status pill (colour-coded)
- Mention count and trend signal (e.g. "↑ 40% this week")
- Score bar indicating priority weight

**Status types**

| Status | Meaning |
|--------|---------|
| Urgent | Needs immediate attention; high volume or legal risk |
| Under review | Being assessed by the product team |
| On roadmap | Committed, being planned or built |
| Backlog | Acknowledged, not yet prioritised |
| Done | Resolved |

**Sample opportunities in prototype**
- Fix checkout payment failures — Urgent, 247 mentions
- Improve mobile search relevance — Under review, 189 mentions
- Clarify seller fee structure — Under review, 164 mentions
- "Unless sold prior" legal compliance — Urgent, Legal / REAA risk
- Watchlist Connect — sold data & reporting — Under review, 18 B2B requests

## Page 2b — Opportunity Detail Pane

![Opportunity detail](screenshots/02b-opportunity-detail.png)

### Description
Clicking any opportunity card opens a slide-in detail pane from the right without leaving the list. This allows quick review without losing context.

### Key Components

**Header**
- Title and auto-generated creation timestamp
- Clickable status pill with a dropdown to change status inline

**Stats grid**
| Stat | Description |
|------|-------------|
| Mentions | Total feedback items referencing this theme |
| Trend | % change in mentions (week-over-week) |
| Sources | Number of distinct data sources contributing |
| Affected users | Estimated unique users impacted |

**Mention Trend (10 weeks)**
A mini bar chart showing weekly mention volume over the past 10 weeks, making it easy to see if an issue is spiking, steady, or declining.

**Sources**
Chips showing which data sources contributed (e.g. Salesforce 142, CSAT 61, NPS 28, Slack 16).

**Tags**
Keyword tags attached to the opportunity (e.g. `payments`, `checkout`, `buyers`, `critical`).

**Sample Feedback**
Two to three verbatim quotes from real feedback items, each labelled with source and timestamp.

**Actions**
- `View related feedback →` — opens Feedback Explorer filtered to this opportunity
- `Size this opportunity →` — navigates to the Sizing page
- `Create Canvas` — generate a product canvas document
- `Create Jira issue` — push the opportunity to Jira

## Page 4 — AI Assistant

![AI Assistant](screenshots/04-ai-assistant.png)

### Description
A conversational chat interface powered by the **Claude API (Anthropic)**. Team members can ask natural-language questions about the feedback corpus and get synthesised, data-grounded answers.

### Key Components

**API Key banner**
A yellow warning bar at the top prompts the user to enter their Anthropic API key to activate the assistant. The key is saved for the session only.

**Suggested questions**
Pre-written prompt pills to help users get started quickly:
- "What are the top issues this week?"
- "What do sellers need most?"
- "Any new trends emerging?"
- "Compare buyer vs seller pain points"

**Chat thread**
- User messages appear right-aligned in a blue bubble
- AI responses appear left-aligned in a grey bubble with an `AI` avatar
- Responses include structured lists and bold key terms

**Response actions**
Each AI response includes action buttons:
- `Export as PDF`
- `Copy summary`
- `Create opportunity →` — turns the AI's answer directly into an opportunity
- `View sizing →` — jumps to the Sizing page for the referenced issue

**Chat input**
A free-text textarea at the bottom with a `Send` button. Supports multi-line input.

**Typing indicator**
Animated dots show while the AI is generating a response.

**Example conversation shown in prototype**

> **User:** What are the biggest issues buyers are facing right now?
> **AI:** Based on the last 30 days of feedback, here are the top buyer issues:
> 1. Checkout payment failures — 247 mentions, up 40% this week...
> 2. Search relevance on mobile — 189 mentions over 3 weeks...
> 3. Watchlist notifications — 97 mentions...

> **User:** Is the payment issue getting worse or stabilising?
> **AI:** It's getting worse. Mentions have increased each day for the past 5 days — from 18 on Monday to 61 yesterday. The spike correlates with a deployment on Tuesday...

A dedicated page to quantify the impact of an opportunity before committing resources. Helps product managers make data-backed roadmap decisions.

### Key Components

**Opportunity selector**
Dropdown to select which opportunity to size. A `+ Compare` button allows side-by-side comparison of two opportunities.

**Summary metrics (top row)**

A bar chart showing weekly volume. Weeks are greyed out when low-signal; the most recent week is highlighted in red to show a spike.

Horizontal bar chart breaking down which user segments are impacted:
- Buyers — 82%
- Mobile users — 65%
- New users — 41%
- Sellers — 18%

Horizontal bar chart showing how many mentions came from each data source (Salesforce, CSAT, NPS, Slack).

A coloured dot rating (e.g. `High — 4 sources`) showing how much confidence to place in the sizing estimate based on data breadth.

**Actions**

## Page 7 — Add Feedback

![Add feedback](screenshots/07-add-feedback.png)

### Description
A manual data entry form for capturing feedback that arrives outside connected channels — e.g. from a user interview, a sales call, a support email, or a conference conversation.

### Form Fields

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| Feedback | Textarea | Yes | Paste the verbatim quote; AI analysis works best on original language |
| Source | Dropdown | Yes | Select where feedback came from |
| Customer type | Dropdown | No | Buyer / Seller / B2B agent / etc. |
| Customer identifier | Text | No | Member ID, email, or anonymous |
| Date of feedback | Date picker | No | Defaults to today |
| Sentiment | Toggle buttons | No | Negative / Neutral / Positive |
| Link to opportunity | Dropdown | No | Manually link, or let AI suggest the best match |
| Tags | Text (comma-separated) | No | Group related ad-hoc feedback before AI clusters it |
| Internal notes | Textarea | No | Context not shown to customers (e.g. who raised it, nuance) |

**Actions**
- `Save feedback` — submits the entry and adds it to the feedback corpus
- `Clear form` — resets all fields

### Tips panel (right sidebar)
- Paste the verbatim quote where possible — AI analysis works best on original language
- Link to an opportunity if known; otherwise AI will suggest the best match
- Use tags to group related ad-hoc feedback before AI clusters it
- Internal notes help the team understand context without polluting the data

### Recently Added Manually
A right sidebar panel showing the last few manually-added entries, with source, user type, contributor, and timestamp. Includes a `View all feedback →` link.

## Technical Notes

- **Framework:** Vanilla HTML/CSS/JavaScript (single-file prototype)
- **Charts:** Chart.js 4.4.1
- **Fonts:** Barlow Condensed (display headings), system sans-serif (body)
- **AI integration:** Anthropic Claude API — requires user-supplied API key entered in the AI Assistant page
- **Colour system:** Trade Me brand tokens (`--tm-blurple`, `--tm-kowhai`, `--tm-charcoal`, `--tm-pink`, `--tm-amber`)
- **Navigation:** JavaScript-driven show/hide of page sections; no page reloads
- **Detail panes/drawers:** Slide-in overlays triggered by clicking list items, using CSS transforms
